# 整体规划 (Planning)

> 更新日期：2026-08-16

## 1. 项目愿景

打造一个个人专属的美食记忆库：记录自己做的每一道菜、去过的每一家店、吃过的每一道美味，形成可回顾、可评分的美食人生记录。

## 2. 功能清单

### P0 — 核心功能（MVP）

| 模块 | 功能 | 优先级 |
|---|---|---|
| 用户系统 | 注册、登录、退出 | P0 |
| 用户系统 | 获取/更新个人信息 | P0 |
| 自制菜谱 | 创建、查看、编辑、删除菜谱 | P0 |
| 自制菜谱 | 食材清单、步骤、难度、耗时、评分、标签 | P0 |
| 自制菜谱 | 列表分页 + 搜索 + 筛选 | P0 |
| 餐厅 | 添加、查看、编辑、删除餐厅 | P0 |
| 餐厅 | 店名、地址、菜系、评分、备注、照片 | P0 |
| 菜品 | 添加、编辑、删除店内菜品 | P0 |
| 菜品 | 价格、评分、口味描述、就餐日期、照片 | P0 |
| 图片 | 多图上传、自动压缩、缩略图 | P0 |
| 多端 | Web + 手机 Web + Android PWA | P0 |

## 3. 里程碑

| 里程碑 | 内容 | 目标 |
|---|---|---|
| M0 | 环境搭建 + 文档 + 脚本 | Phase 0-1 |
| M1 | 数据库就绪 + Go 后端全部 API | Phase 2-3 |
| M2 | Vue 前端全部页面 + PWA | Phase 4 |
| M3 | Docker 部署 + 集成验证 | Phase 5 |
| M4 | （可选）增强功能迭代 | 后续 |

## 4. 迭代计划

### 迭代 1：基础框架（Phase 0-1）
- 根目录：docker-compose / env / README
- 文档：架构、规划、进度、API 骨架、数据库设计
- 脚本：start-dev / migrate / seed / build / docker-build
- 后端：Go module、配置、DB 连接、Gin 骨架
- 前端：Vite + Vue3 + Element Plus + PWA 脚手架

### 迭代 2：后端 API（Phase 2-3）
- 数据库迁移 SQL
- 认证模块（注册/登录/me）
- 菜谱 CRUD + 筛选分页
- 餐厅 CRUD + 菜品 CRUD
- 图片上传与处理
- 中间件（JWT / CORS / 日志）

### 迭代 3：前端页面（Phase 4）
- 认证页面
- Dashboard
- 菜谱列表/详情/表单
- 餐厅列表/详情/表单/菜品
- 个人中心
- PWA 配置

### 迭代 4：集成与部署（Phase 5）
- 前后端联调
- Docker 全容器部署
- PWA 安装验证
- 进度文档更新

## 5. 验收标准

1. 用户可注册登录，token 有效期内免登录
2. 可完整创建一条菜谱（含图片上传、食材、步骤）
3. 可完整记录一家餐厅及多道菜品并评分
4. 列表支持分页、搜索、筛选
5. 移动端可安装为 PWA 应用
6. `docker-compose up -d` 一条命令启动全部服务
